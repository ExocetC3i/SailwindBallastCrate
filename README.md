# SailwindBallastCrate
Spawn a 10 tonne crate for ship ballast. Intended to be used with the Better Drag mod and large modded ships

Press **F6** to spawn a standard sized crate weighing 10,000 kg (10 tonnes) in front of you.

Special thanks for code inspiration from NANDBrew, raddude, and Kemylar from the Sailwind Discord.
